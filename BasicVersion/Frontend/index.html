Help / FAQ

How do I add a task?
Type into the input box and click "Add" or press Enter.

How do I mark a task as complete?
Click the checkbox next to the task — it'll show a strikethrough.

How does priority work?
Each task has a priority (Low/Medium/High) you can change from its dropdown. Use "Priority Tasks" in the sidebar to sort by priority.

How do I filter tasks?
Use "Completed" or "Pending" under Tasks in the sidebar to filter your view.

Can I change the default priority for new tasks?
Yes — set it under Settings → Default Priority.

How do I clear everything?
Settings → Clear All Tasks. This can't be undone, so you'll be asked to confirm.

Can I change the look of the app?
Yes — use the Themes menu in the top-right to switch between Dark, Light, Pink, or System default.
