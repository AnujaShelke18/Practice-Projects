# Practice Projects

A collection of small projects built while learning full-stack web development — vanilla JS, DOM manipulation, theming, and (progressively) backend/database integration.

## Projects

### 📝 [To Do App](./ToDoApp)
A to-do list app with task priorities, search/filter, theming, and a settings panel. Built with vanilla JS in an MVC-style structure.

### 🌤️ [Weather App](./WeatherApp)
A weather dashboard with city search, current conditions, sunrise/sunset times, and a 7-day forecast, styled with a glassmorphism UI. Built with React and Vite using the Open-Meteo API.
